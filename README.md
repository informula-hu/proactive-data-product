# Proactive Data Product – Definition

**Current version: 1.0** · first published 5 November 2026, Budapest · publisher: INFORMULA Kft. · licence: CC BY 4.0

> A **proactive data product** is a real-time data product of a business entity – customer, contract, transaction, interaction, risk or consent – with a named owner and a contract. It not only serves its current state on request (**state view**), but also publishes business-meaningful events on its own (**event view**) – to people, systems and AI agents.
